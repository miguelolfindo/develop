# Lensfun lens database

These XML files are the lens and camera calibration database of the Lensfun project
(https://github.com/lensfun/lensfun, `data/db`, master branch as of 2026-11-15).

They are licensed under the Creative Commons Attribution-ShareAlike 3.0 license
(CC BY-SA 3.0), © the Lensfun contributors. Develop reads them unchanged for its lens
correction; the installer ships this folder next to the program.

To update, replace the `.xml` files with newer ones from the same folder of the Lensfun
repository.
